# Install for Claude Code

Recommended: add this repository as a marketplace, then install the plugin from that marketplace.

## Marketplace install

```bash
claude plugin marketplace add ZephyrCICD/ai-skill-git-commit-assistant
claude plugin install git-commit-assistant@git-skills
```

## Use it

```text
$draft-commit-message
```

```text
$commit-changes
```

The legacy shorthand terms `ggm` and `ggm-p` remain in the skill descriptions for compatibility
with older prompts, but new installs should use the clearer names above.
